Процес збірки та нумерації версій AirHub

1. Середовище
- IDE: IntelliJ IDEA, JDK 25.
- Система збірки: Maven (pom.xml). Залежності (H2, FlatLaf) завантажуються з Maven Central автоматично,
  jar-файли бібліотек вручну не передаються.
- Контроль версій: Git.

2. Збірка
- У IDE: проєкт відкривається як Maven-проєкт, запуск - клас org.grebenyk.airhub.App.
- З командного рядка:
    mvn test                             - запуск тестів (src/test/java)
    mvn clean package                    - тести, компіляція і збірка target/airhub-<версія>.jar
    java -jar target/airhub-<версія>.jar - запуск
- Плагін maven-shade-plugin вкладає бібліотеки в jar і вказує головний клас,
  тому для запуску потрібен лише цей один файл і JDK 25.
- Ресурси (schema.sql, init.sql) входять у jar; база створюється при першому запуску в теці data.
- Каталоги target і data у Git не зберігаються (.gitignore).

3. Нумерація версій
- Формат MAJOR.MINOR.PATCH (наприклад, 1.2.0):
    MAJOR - несумісні зміни (структура БД, яка потребує перестворення бази);
    MINOR - нові функції (нова форма, звіт);
    PATCH - виправлення помилок.
- Під час розробки версія має суфікс -SNAPSHOT (1.1.0-SNAPSHOT).
- Версія задається тільки в pom.xml; при збірці вона записується в маніфест jar,
  і вікно "Про програму" показує її автоматично.
- Випуск: прибрати -SNAPSHOT у pom.xml, зібрати, зробити коміт і тег v1.1.0,
  потім підняти версію до наступної -SNAPSHOT.

4. Робота кількох програмістів
- Основна гілка main завжди збирається і запускається.
- Кожен програміст працює в окремій гілці feature/<завдання> (наприклад, feature/stats-form).
- Модулі розподіляються за класами: доступ до БД (Db, DbServer, SQL-скрипти), форми (TableForm, StatsForm ...),
  головне вікно (MainFrame); зміни в спільних класах узгоджуються.
- Перед злиттям у main: оновити гілку з main, зібрати проєкт (mvn package), перевірити запуск.
- Зміни структури БД вносяться тільки через schema.sql / init.sql, щоб у всіх була однакова база.
- Код оформлюється за стандартом кодування (docs/Стандарт кодування.txt).
