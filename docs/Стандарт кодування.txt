Корпоративний стандарт кодування проєкту AirHub (Java, SQL)

1. Вибір імен
- Імена змістовні, англійською, без транслітерації: flight, airline, status.
- Класи - іменники: TableForm, DbServer, FlightTrigger. Суфікс Form - внутрішнє вікно, Frame - головне вікно.
- Методи - дієслова: reload(), applySearch(), cleanLog(), showHelp().
  Методи, що лише повертають значення, можуть називатися іменником-результатом: header(), setting(), icon().
- Булеві методи і поля - з префіксом is/can: isAdmin(), canEdit.
- Короткі імена (i, r, n, e, c, st, rs, cb) - тільки для локальних змінних з малою областю видимості
  (лічильники циклів, параметри лямбд, JDBC-об'єкти).

2. Тип в ідентифікаторі
- Угорська нотація і суфікси типу (strName, iCount, x_float) не використовуються.
- Множина в імені позначає колекцію або масив: filters, params, STATUSES.

3. Регістр символів
- Пакет - нижній регістр: org.grebenyk.airhub.
- Клас, record - "верблюжий" з великої (PascalCase): MainFrame.
- Метод, поле, змінна - "верблюжий" з малої (camelCase): lookupValues, dateCol.
- Константа - верхній регістр, слова через "_": STATUSES, FLIGHT_NO.
- Таблиця, колонка БД - нижній регістр через "_": user_log, sched_time, airline_id.
- Функція/процедура БД - верхній регістр через "_": GET_SETTING, CLEAN_LOG. Тригер - суфікс _trg: flights_trg.
- Ключові слова SQL - верхній регістр: SELECT, CREATE TABLE.
- Підкреслення в Java - тільки в константах.

4. Відступи
- 4 пробіли, табуляція не використовується.
- Перенесений рядок - відступ 8 пробілів.
- Довжина рядка - до 140 символів.
- Багаторядкові SQL і HTML - текстові блоки """.

5. Дужки
- Стиль K&R: "{" в кінці рядка заголовка, "}" на окремому рядку.
- else, catch пишуться на рядку із закривною дужкою: } catch (SQLException e) {
- Дужки можна опустити лише для однієї інструкції на тому ж рядку: if (row < 0) return;

6. Пробіли
- Навколо бінарних операторів і присвоєння: a + b, i < n, x == null, a && b, v = 0.
- Без пробілу для унарних: -days, !text.isEmpty(), i++.
- Після коми і після if, for, while, catch: for (int i = 0; i < n; i++).
- Без пробілу між ім'ям методу і "(" та всередині дужок: reload(), (a + b).
- Після приведення типу і навколо "->": (Number) value, e -> reload().

7. Коментарі
- Код самодокументований: зрозумілі імена замість пояснень, коментар не повторює код.
- Коментарі англійською, тільки для неочевидного ("чому", а не "що").
- Однорядковий - "//" на окремому рядку перед кодом; у SQL - "--".
- Javadoc "/** */" - для класів і методів з неочевидним призначенням.
- Закоментований код не залишається.

8. Магічні числа
- Літерали з неочевидним змістом виносяться в константи static final:
  private static final int FLIGHT_NO = 1, STATUS = 7;
- Допустимі значення (статуси, типи, ролі) - константи-масиви: STATUSES, TYPES, ROLES.
- Параметри, які змінює адміністратор, зберігаються в таблиці settings: GET_SETTING('log_keep_days').
- Без констант дозволені: 0, 1, -1; номери параметрів і колонок JDBC (setString(1, ...));
  індекс 0 колонки id.
