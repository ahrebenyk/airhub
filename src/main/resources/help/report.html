6. Звіт: розклад рейсів

Меню Файл → Звіт: розклад рейсів (потрібне право звітів).

Звіт показує всі рейси, впорядковані за часом за розкладом, з колонками: Час, Рейс, Авіакомпанія, Тип, Місто, Гейт, Статус. Клацання по заголовку колонки змінює сортування. Звіт доступний лише для читання.

Щоб скопіювати звіт, виділіть рядки (Ctrl+A — усі) і натисніть Ctrl+C; дані можна вставити в Excel або Word.
